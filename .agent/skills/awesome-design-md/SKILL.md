# Awesome DESIGN.md Guidelines

A comprehensive catalog of brand design languages from top tech companies:
- **Stripe**: Pristine gradients, micro-interactions, high-contrast badges, crisp typography.
- **Linear**: Dark mode mastery, high density, subtle borders, precision keyboard-first design.
- **Vercel**: Minimalist monochrome with geometric accents, extreme contrast, tight kerning.
- **Apple**: Generous padding, soft blurs, human interface guidelines, accessibility.
- **Supabase**: Emerald accents, developer-focused ergonomics, clean cards.
- **Wise / Mercury**: Modern financial SaaS clarity, warm accents, confidence-inspiring typography.

Refer to design-md/<brand>/DESIGN.md for specific brand tokens, palettes, and rules.
